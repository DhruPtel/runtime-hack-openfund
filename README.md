# Openfund

Hello Runtime.

Openfund is an onchain fund that holds tokenized equities on Robinhood Chain and
rebalances itself: parallel analyst agents research a frozen market snapshot, a
risk agent can veto the resulting plan, and a single treasurer executes it. Every
decision is signed and published, and the fund's own books — revenue, costs, and
P&L — are reconciled and open.

Built for the Runtime hackathon.
